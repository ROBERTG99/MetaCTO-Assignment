# Distill web app

React 19, TypeScript (strict), Vite, Tailwind v4 with shadcn/ui on Radix, TanStack Query, React Router. Run it from the repo root:

- `make dev`: the API on :8000 (with its worker) and this app on :5173; the browser calls `/api`, which Vite forwards to the API.
- `make gen-api`: regenerate `src/api/schema.d.ts` from `backend/openapi.json` (after `make openapi`). API types are never written by hand.
- `make typecheck-web`, part of `make check`.
- `make e2e`: the golden paths in `e2e/` (test-plan §4) against a fresh offline API on :8001 and this app on :5174.

`src/components/ui/` is generated by the shadcn CLI and left as generated.
